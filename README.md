# 👑 Noor’s World

> *"Forever is a dangerous word, for can a mortal offer eternity?"*

**Noor’s World** is an interactive personal website designed to document life stories, personal reflections, and future aspirations. The project explores human transformation and constant growth through visual storytelling and web design.

### 🎓 Project Context
Created as a final portfolio project submission for the **Girls Who Code** program to review and practice beginner web development fundamentals (HTML, CSS, and JavaScript). Built purely for creative fun, self-expression, and positive inspiration!

### 📖 Site Structure
- **Home:** Introduces the core philosophy of personal evolution and transformation.
- **Life:** Highlights childhood memories, family roots, and key life milestones.
- **Dreams:** Visualizes future goals, creative ambitions, and vision.
- **About:** Details the purpose, heart, and inspiration behind the project.

### 🛠️ Built With
- **HTML5** — Semantic layout & multi-page navigation
- **CSS3** — Custom styling & visual layout
- **JavaScript** — Interactive features
